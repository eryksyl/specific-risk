# Stock-portolio-analysis
This project represents an advanced investment portfolio audit tool, integrating **Sharpe’s Single-Index Model (SIM)**. 
The system evaluates assets not just through raw profit, but primarily through the quality of delivered returns, decomposing risk into **Systematic (Market)** and **Idiosyncratic (Specific)** components.

## 🚀 LIVE APPLICATION
**[Click HERE to launch the app](https://specific-risk.streamlit.app/)**



* **Language:** Python
* **Interface:** Streamlit (Web Dashboard)
* **Data Source:** Yahoo Finance (yfinance API)
* **Key Features:** Specific Risk Audit, $R^2$ Diversification Check, Cointegration (Twin-Stock) Detection.
